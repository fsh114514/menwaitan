## 功能

- **思想者阵容** —— 每位思想家一份 SKILL.md，由开源社区蒸馏（26+ 位）
- **对谈 / 圆桌** —— 单聊，或让多位思想家轮流交锋
- **场景系统** —— 随口 / 较真 / 上头 控制回答长短与火候，气氛上来自动升级
- **联网查梗** —— 遇到不懂的梗/名词，角色会先联网检索再回答（免费多源）
- **流式回复** —— SSE 打字机效果
- **人物志** —— 每位的背景、名言、源码仓库
- **BYOK** —— 自带 API key，或直接用内置免费通道（智谱 GLM-4-Flash）
- **触屏拖拽** —— 手机长按调整座位，全端响应式

## 使用指南

### 1. 选人入席
- 在「人物志」或左侧人物列表**点选角色**：选 **1 位 = 单人对谈**；选 **2 位以上 = 圆桌辩论**
- 圆桌时可在左侧「回答顺序」里调整谁先开口（上移 / 下移）

### 2. 提问
- 在输入框写下你的问题，点「**发言**」或按回车
- 回答会一个字一个字冒出来——这是流式生成，别急
- AI 说话时点「**⏸ 停止**」立即中断（已说的内容会保留）；直接输入新问题再回车 = 插话，旧回答会被打断

### 3. 交锋火候（场景）
- **随口**：两三句，先碰个面
- **较真**：认真辩，有来有往（默认）
- **上头**：放开打，不设限
- 聊到兴头上会自动升级，气氛越激烈回得越长

### 4. 联网查梗
问「XX 是什么 / 什么意思 / 为什么」这类问题时，角色会**自动联网检索**最新网络梗（必应/360/萌娘百科等多源），回复前会附一行「注：据网络检索，…」。搜不到也不影响正常聊天。

### 5. 回看发言
辩论进行中**可以往上翻看历史**，不会被强制拉回底部；点「**回到最新**」一键跳回。

### 6. 中英切换
右上角「EN / 中」一键切换界面语言。

### 7. 自带 API Key（可选）
- 不填也能用（走站点默认免费通道）
- 想用自己的：进入「设置」→ 填 API Key / Base URL / 模型（DeepSeek、Kimi、智谱、通义、OpenRouter 等任意 OpenAI 兼容服务）→ 保存
- Key 只存在你自己的浏览器本地，不会上传服务器

### 8. 创意工坊（导入新角色）
- 粘贴一个含 SKILL.md 的 GitHub 仓库 URL → 点导入，新角色几秒后出现在人物志

### 9. 快捷键
- 回车：发送 / 插话
- 发送键三态：**发言** → **⏸ 停止**（AI 说话时）→ 重新输入即继续

## 快速开始（开发）

```bash
pnpm install
cp .env.local.example .env.local   # 填入你的 AI_API_KEY（GLM-4-Flash 免费）
pnpm dev
```

打开 http://localhost:3000。生产构建：

```bash
pnpm build && pnpm start -p 3100
```
