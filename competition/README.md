## 作品核心（一句话）

v1 的圆桌里所有人共享同一份上下文，于是迅速趋同、产生伪共识。
v2 给圆桌加了一层「**谁知道什么**」——

1. **可见性**：发言带 `public` / 仅某人可见标签，进 prompt 前按可见集合裁剪
2. **悄悄话**：用户可以私下对某一位人物说话，桌上其他人看不到
3. **点名对质**：收到悄悄话的人会当众点名对方（被点名者不许用「我同意」开场）
4. **信息新颖度**：字符 2-gram 不重叠率，低于 0.34 判定趋同 → 强制提出反对意见

代码在分支 `cmit-2026`（`0bc0458` → `b2ffeb1`），改动集中在
`app/api/chat/route.ts` + `app/page.tsx` + `app/revolution/revolution.css`。
