## 3、作品简介

```
门外谈是一个 AI 思想家对谈与圆桌辩论网站，全站中英双语。

站内提供几十位可对话的思想家人格（鲁迅、马克思、孔子、乔布斯、马斯克、巴菲特等），人格取自开源社区蒸馏的 SKILL.md。用户可选一位单人对谈，或选多位组成圆桌，看他们对同一议题各执一词；也可在创意工坊导入新的人格。

v2 的核心创新是给圆桌加了一层「信息层」：发言可以只让某一位看到，用户可以私下对某个角色说话，桌上其他人完全不知道。被私下告知的人会带着这条信息当众点名对方，讨论从轮流发言变成带有暗流的博弈。系统还会计算每一轮的新信息比例（字符 2-gram 重叠率），判定讨论在互相附和时强制提出反对意见；仍无新意则由「门外谈」本人出面收尾，拆穿伪共识。

作品为 Web 应用，免费、无需注册，支持自带 API Key，已上线 outgate.chat。
```

## 4、创意来源

```
最初的目的很简单：想找个能真正交流的 AI。

日常用 AI 问问题，得到的回答大多很客气。问「我该不该放弃这个专业」，回答是这取决于你的兴趣和目标；问「我这样想对不对」，它先说你的想法很有道理。次数多了会发现，聊完之后那个疑问还在原处。

后来在 GitHub 上看到，有人把名人整理成可以对话的人格包（SKILL.md），接入之后 AI 会用那个人的语气说话。我试了几个，比较意外的是这些角色并不好说话。问鲁迅该不该退学，他并不分析利弊，而是反问：凭什么认为退学是一条路。这种被追问的感觉，比被安慰更有用。

不过一次只能和一个人对话，本质上仍然是我问他答。我更好奇的是他们彼此之间的分歧——把鲁迅和乔布斯放在一起讨论「要不要为了稳定放弃热爱」，这两位的立场几乎不可能调和。

于是做了圆桌：提出一个议题，几位依次发言，后发言的人能看到前面说了什么。

实际用下来，有一件事比较扫兴：他们很快会趋同。前面的人说了什么，后面的人便顺着说，几轮之后气氛变得融洽，和最初那种「你的想法很有道理」并没有本质区别。原因在于他们掌握的信息完全相同，没有人比别人多知道一点什么。

后来才补上这一层：发言可以只对某一位可见，我可以私下告诉某个角色一些其他人不知道的事。他带着这条信息回到台面，当众向对方提出质疑。讨论到这里才更像真实的讨论——桌上有人掌握着别人不知道的信息，有人被突然点名。
```

## 5、运行环境

```
终端：台式机 / 笔记本 / 手机 / 平板均可，无特殊硬件要求。
操作系统：Windows 10 及以上、macOS 12 及以上、iOS 15 及以上、Android 10 及以上。
浏览器：Chrome、Edge、Safari、Firefox 等现代浏览器（需支持流式响应 SSE）。
内存：4G 及以上即可流畅运行，无需独立显卡。
网络：需联网访问 https://outgate.chat，普通宽带或移动网络均可。
客户端无需安装任何软件，无需注册账号，打开网页即可使用。

服务端（供参考）：Node.js 20 + Next.js 16，部署于阿里云香港服务器，nginx 反向代理 + HTTPS。
```
