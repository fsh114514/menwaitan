## 二、⚠️ 部署前必须知道的一件事

**CI 只在 `main` 分支触发，而且 `main` 现在被刻意冻结在 v1。**

所以有两种做法：

### 做法 A（推荐，可控）：本地构建镜像 + 推送
不改 `main`，直接用 `cmit-2026` 的代码构建并推镜像。

**做法 B：把 `cmit-2026` 合进 `main`**
合了之后 CI 会自动构建推送，但**线上会立刻变成 v2**，且 `main` 不再等于"线上已验证版本"。
如果 v2 出问题，回滚要重新部署 v1。

**建议先用 A，稳定几天后再考虑合 `main`。**

## 三、做法 A 的操作步骤

### 1. 确认本地能跑、能构建

```bash
cd "/Users/shf/Documents/DeepSeek harness/sixiangjia web"
git checkout cmit-2026
git log --oneline -1              # 应显示最新的 v2 提交

npx tsc --noEmit                  # 期望退出码 0
npx next build                    # 期望 Compiled successfully
```

### 2. 构建并推送镜像

```bash
docker build -t <你的DockerHub用户名>/menwaitan:v2 .
docker tag <你的DockerHub用户名>/menwaitan:v2 <你的DockerHub用户名>/menwaitan:latest
docker login
docker push <你的DockerHub用户名>/menwaitan:latest
```

> 如果本机没装 Docker：可以直接在服务器上 `git clone` + `podman build`，
> 或临时在 `main` 上打一个 tag 触发 CI（但那样 CI 会把它当 `main` 构建）。

### 3. 在服务器上更新容器

```bash
ssh <你的服务器>
podman pull docker.io/<你的DockerHub用户名>/menwaitan:latest
podman stop menwaitan && podman rm menwaitan
podman run -d --name menwaitan \
  -p 3100:3100 \
  -v /srv/menwaitan/skills:/app/skills \
  -v /srv/menwaitan/data:/app/data \
  --env-file /srv/menwaitan/.env \
  --restart=always \
  docker.io/<你的DockerHub用户名>/menwaitan:latest
```

> **卷（volume）要保留**：`/app/skills` 是人格素材、`/app/data` 是历史与反馈。
> 容器内首次启动会把内置人格 seed 进卷，**卷已存在时不会覆盖**。

### 4. skills 卷同步（v2 没有新增人格，通常不用做）

v2 只改了 `app/`，**没有动 `skills/`**，所以这一步一般可跳过。
若确实需要同步：

```bash
tar czf skills.tgz skills/
scp skills.tgz <服务器>:/srv/menwaitan/
ssh <服务器> "podman cp /srv/menwaitan/skills.tgz menwaitan:/tmp/ && \
  podman exec menwaitan sh -c 'cd /app && tar xzf /tmp/skills.tgz'"
```

## 四、部署后必须验证的 4 件事

按顺序做，**任何一条不过就回滚**：

```bash
# 1. 首页通不通
curl -s -o /dev/null -w "%{http_code}\n" https://outgate.chat/          # 期望 200

# 2. 人物列表通不通（45 位）
curl -s https://outgate.chat/api/characters | head -c 200

# 3. 悄悄话接口真的在（v2 的标志）
curl -s -X POST https://outgate.chat/api/chat \
  -H "Content-Type: application/json" \
  -d '{"characters":["luxun","steve-jobs-skill"],"mode":"debate","lang":"zh",
       "whisperOnly":"luxun",
       "messages":[{"role":"user","content":"你怎么看？"},
                   {"role":"assistant","who":"乔布斯","content":"工具会变，品味不会。"},
                   {"role":"user","content":"乔布斯不赞同你，当面问他。","whisperTo":"luxun"}]}' \
  | grep -c '"type":"who"'      # 期望 1 —— 只有一个人被唤起就是 v2
```

4. **浏览器手动走一遍**：选两个人 → 点卡片上的「私」→ 输入一句话 → 发送
   → 应看到红色状态条 + 消息带锁标记 + 之后自动接一轮公开圆桌。
