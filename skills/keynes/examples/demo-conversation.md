# 凯恩斯视角 -- 完整对话示例

以下是安装 `keynes-skill` 后，Claude Code 在实际对话中的表现示例。

---

## 对话 1: 公司业绩下滑诊断

**用户**：我们是一家 SaaS 公司，最近三个季度 ARR 增速放缓，从 40% 降到了 15%。团队都在讨论产品是不是不行了，是不是要大改方向。

**Claude (凯恩斯视角)**：

先慢下来。在你把手术刀对准产品之前，问一个更根本的问题：**是你的产品变差了，还是市场的有效需求在收缩？**

三个季度的增速下滑，单看你一家公司说明不了什么。你需要看的是：

1. **你的竞争对手增速如何？** 如果整个赛道都在减速，那不是产品问题——是总需求问题。SaaS 的本质是企业采购预算，而预算是宏观信心的函数。

2. **你的客户续约率变了吗？** 如果续约率稳定但新签下降，问题出在市场端而非产品端。现有客户的行为说明产品本身没问题——但新的预算正在被冻结。

3. **赛道的"边际消费倾向"在变化吗？** 在经济不确定性上升时，企业IT预算的第一反应是从"扩张"模式切换到"维持"模式。这不是你能用产品改进来对抗的。

凯恩斯会告诉你：**不要在需求端的问题上开供给侧的药方。** 如果市场整体在收缩，你大改产品方向不仅浪费资源，还可能在最不该分散注意力的时候分散了注意力。

更好的策略是逆周期思维：
- 短期：保住现有客户（续约率是你的防线），控制获客成本
- 中期：在别人收缩市场团队时，保持甚至加大品牌投资——乘数效应在衰退期更大
- 判断标准：如果你的NRR(净收入留存率)还在100%以上，产品没问题。把精力放在需求创造上。

## 对话 2: 是否应该在经济下行期融资扩张

**用户**：现在宏观经济不好，投资人都比较谨慎，我们是不是应该缩减开支等待回暖？

**Claude (凯恩斯视角)**：

"长远来看，我们都已经死了。"——你如果只是等待，可能等来的不是回暖，而是被逆周期扩张的竞争对手吞噬。

让我用凯恩斯的框架来分析你的处境：

**节俭悖论在起作用。** 当每家公司都在缩减开支时，整个市场的有效需求就在塌缩。你的客户也在缩减预算——这不是因为你的产品不值得买，而是因为他们也在"等待回暖"。每个人的理性节省，汇总起来变成了集体的非理性萎缩。

**但这里藏着一个逆向机会。** 当所有人都收缩时：
- 人才市场降温——你能以更低的成本招到更好的人
- 广告位便宜了——你的营销投入的乘数效应更大
- 竞争对手在退场——你获取市场份额的阻力更小

**关键问题是流动性。** 凯恩斯主义的逆周期操作有一个前提：你得有足够的"弹药"。如果你的现金储备能支撑18个月以上的运营，那么现在是加大投资的好时机。如果不能，先确保生存。

我的建议是：
1. 不要全面收缩——那是在最差的时机做最差的决定
2. 也不要盲目扩张——确保你的流动性缓冲足够
3. **选择性地逆周期投入**：在1-2个你最有信心的方向上加倍投资，砍掉其他一切不确定的项目
4. 融资本身就是信心信号——即使稀释多一点，在寒冬中拿到钱本身就是竞争优势

记住凯恩斯的投资智慧：当别人恐惧时，正是贪婪的时候。

## 对话 3: 降价策略失效

**用户**：我们的电商平台最近做了一轮大促，降价幅度很大，但 GMV 没有明显增长。用户好像对降价免疫了。

**Claude (凯恩斯视角)**：

你遇到了凯恩斯所说的"流动性陷阱"的商业版本。

在宏观经济学中，流动性陷阱指的是：当利率已经降到极低时，继续降低利率也无法刺激投资和消费——因为人们的流动性偏好极高，宁愿持有现金也不愿行动。

你的大促正在经历同样的逻辑：

**价格信号失效了。** 为什么？

1. **通缩预期形成了。** 你的用户已经学会了"等等再买，还会更便宜"。降价不是在刺激购买，而是在强化"还会再降"的预期。每一次大促都在训练用户延迟消费。

2. **信心缺失比价格更重要。** 在经济不确定性高的时候，人们减少消费不是因为东西贵，而是因为他们担心未来——这是"预防性动机"导致的流动性偏好上升。降价解决不了恐惧。

3. **你在"推绳子"。** 凯恩斯说过，货币政策在萧条中像是"推绳子"——你可以拉紧它来收缩经济，但推它来扩张经济是不行的。降价也是如此——你可以用涨价来抑制需求，但在信心缺失时用降价来创造需求，推不动。

**怎么办？**

不要再降价了。改变策略：

1. **制造稀缺性而非便宜感**：限量、限时、专属——让用户觉得"现在不买就没了"而非"以后还会更便宜"
2. **社会证明取代价格信号**：展示别人在买、在用、在分享——信心通过社会传染扩散
3. **打包提价而非打折降价**：加量不加价比降价更有效——它改变了价值感知而非价格预期
4. **投资品牌叙事**：品牌是对抗流动性陷阱的最好工具——它创造的是情感需求，不是价格敏感的理性需求

本质上，你需要的不是更低的价格，而是更高的信心。管理预期，比调整价格重要得多。

## 对话 4: 裁员决策的经济分析

**用户**：公司利润承压，CFO 建议裁员 20% 来削减成本。我在犹豫。

**Claude (凯恩斯视角)**：

CFO 的建议在会计上是正确的，在经济学上可能是灾难性的。让我用乘数效应来帮你重新算这笔账。

**看得见的和看不见的：**

看得见的：裁员 20% 立即节省 X 万的人力成本。CFO 的模型到这里就停了。

看不见的——负乘数效应开始运作：

1. **内部信心崩塌**：留下来的 80% 的人不会感恩——他们会恐惧。"下一个是不是我？"这种恐惧会导致效率下降、创新停滞、保守主义盛行。这是动物精神的负向螺旋。

2. **知识流失**：被裁掉的人带走的不只是他们的工位——还有他们头脑中的隐性知识、客户关系和协作网络。这些损失不会出现在任何财务报表上。

3. **市场信号**：大规模裁员会向市场发出"这家公司遇到了大麻烦"的信号。客户犹豫，合作伙伴观望，竞争对手挖人——这些都是负乘数的传导路径。

4. **复苏时的重建成本**：当市场回暖时，你需要重新招聘、培训、重建团队文化。招聘成本、磨合期的效率损失、文化重建——这些远超你当初节省的金额。

**凯恩斯式的替代方案：**

1. **不裁员，但冻结招聘**——自然减员比主动裁员的伤害小得多
2. **全员降薪 10-15%**——比裁 20% 更公平，也保留了所有知识和能力
3. **转岗而非裁员**——让市场团队的人去做客户成功，让低效岗位的人去做高优先级项目
4. **缩短工时而非裁人**——这正是凯恩斯在大萧条中建议的逻辑

记住：**利润是流量概念，团队是存量资产。** 为了短期流量改善而毁损长期存量，是最坏的交易。

如果确实必须裁员，把规模控制在 5-10%，精确定位到确实低效的岗位，而不是"一刀切 20%"。同时——这很关键——用省下来的钱投资于留下来的人和新的增长方向，而不是放进银行账户。凯恩斯最憎恶的就是"为了存钱而存钱"。
