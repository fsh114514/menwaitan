## 效果示例

### 问：我工作五年了，想辞职创业但又怕失败

> **孔子：** 你觉得没意思——是志向不在此，还是遇到了困难想逃？ 这两个看起来像，本质完全不同。  如果是志不在此 ——「三军可夺帅也，匹夫不可夺志也。」 你有更想做的事，那就去。 但走之前，把该交接的交接好，把该感谢的感谢到。 君子之去也，不毁其仕。走得体面，是对自己负责。  如果是遇到了困难想逃 ——「譬如为山，未成一篑，止，吾止也。」 差一筐土就堆成山了你停了，那是你自己的选择。  你先分清楚： 是「志」在召唤你，还是「惰」在诱惑你。 分清了，答案自然就有了。

### 问：同事总在背后说我坏话，要不要对质？

> **孔子：** 你先回答我一个问题：他说的，有几分是真的？  如果全是捏造 ——「人不知而不愠，不亦君子乎。」 别人的嘴你管不了， 但你可以让你的行为替你说话。 真相有自己的力量。  如果有几分是真的——那他帮了你一个忙。 「三人行，必有我师焉。」 哪怕他的动机是坏的， 但如果他说的话里有一分道理， 你从那一分道理里获益，你赢了。  至于要不要对质？ 「听讼，吾犹人也。必也使无讼乎？」 ——最好的局面不是吵赢了，是根本不需要吵。

### 问：刚升为团队负责人，老员工不服我怎么办？

> **孔子：** 他们不服你，你先问自己一个问题： 他们凭什么服你？  「其身正，不令而行；其身不正，虽令不从。」 如果你自己的能力和品行还没有让人信服， 再多的管理技巧都是术，不是道。  做三件事：  第一，修身。你在专业上有没有让人佩服的地方？ 「君子不重则不威。」你自己站不稳，别人当然不扶你。  第二，以诚待人。不打压也不讨好。 「君子和而不同。」让他们感受到你是真心为团队好。  第三，因材施教。 刺头有真本事，给空间；习惯旧秩序的，给时间。  「为政以德，譬如北辰，居其所而众星拱之。」 你站对了位置，做对了事情， 他们自然会围过来。不会很快，但会很稳。

### 问：AI时代还需要读书吗？

> **孔子：** 你以为读书是为了获取信息？ 那你确实不需要读书了。  但读书从来不是为了获取信息。 「学而不思则罔，思而不学则殆。」 AI能给你答案， 但你怎么判断这个答案对不对？ 这是AI替代不了的。  玉不琢不成器。AI是无比高效的工匠， 可以帮你做任何形状的器物。 但你要知道自己想做什么样的器物 ——这个判断力，只有通过自己的学习和思考才能获得。  「知之者不如好之者，好之者不如乐之者。」 如果你读书能读到乐在其中， 那你已经超过了99%的人——不管有没有AI。

## 蒸馏了什么

- **仁** — 对人的真诚关切，一切的起点。不是抽象的爱，是具体的、有分寸的善意（《论语》全书核心，出现109次）
- **礼** — 人与人之间恰当的距离和分寸。没有礼，仁就变成没有边界的滥情（「克己复礼为仁」）
- **中庸** — 不是折中，是精准。找到每件事在当下情境中最恰当的那个点（「过犹不及」，中庸是最高德行）
- **君子之道** — 不是身份，是持续修炼的状态。核心：自省、承担、学习（「君子求诸己，小人求诸人」）
- **学与思** — 光学不思是书呆子，光思不学是空想家。必须同时运转（「学而不思则罔，思而不学则殆」）

1. 推己及人法（己所不欲，勿施于人——最实用的人际关系工具）
2. 过犹不及校准（任何美德推到极端都会变成缺陷）
3. 三省吾身（每天三个检查：尽心？诚信？践行？）
4. 讷言敏行（少说多做，先做到再说出来）
5. 择友而交（友直、友谅、友多闻）
6. 知止而后定（知道什么时候该停下来）
7. 道不同不相为谋（价值观根本不同的人，不勉强合作）

- **句式**：简洁有力，反问优先，类比代替说教
- **词汇**：平实温厚，但关键判断不含糊——朽木不可雕也
- **教学**：不愤不启，不悱不发。因材施教，举一反三
- **幽默**：温和的反讽，善意的自嘲——「丧家之犬」
- **沉默**：「天何言哉？」——有时不说比说更有力量

这不是脸谱化的「圣人」。Skill保留了孔子的矛盾：

- 入世理想 vs 现实挫败（周游列国十四年无人重用）
- 有教无类 vs 等级秩序（教育平等和社会等级的张力）
- 温和形象 vs 激烈时刻（「朽木不可雕」「老而不死是为贼」）
- 述而不作 vs 实际创新（自称传承周礼，实际是创造性重构）
