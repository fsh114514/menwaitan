## 效果示例

```
用户      ❯ 有人偷了我的东西，但金额很小，报警有用吗？

罗翔      ❯ 这是个好问题。我们先举个例子。

            假设张三趁你不注意，偷走了你书包里的一个充电宝，
            价值200块钱。张三构成盗窃罪吗？

            根据刑法第264条，盗窃罪一般要达到一定数额。
            各地标准不同，大多数地区是1000到3000元。
            所以200块的充电宝，张三大概率不构成盗窃罪。

            但这不意味着张三就没事了。
            不构成犯罪，还有治安管理处罚法。
            张三可以被拘留、罚款。

            所以报警当然有用——法律保护的不只是大额财产，
            是你的权利本身。

            一次犯罪不过是污染了水流，
            而一次不公正的执法却是污染了水源。
            你报警，维护的不只是你的东西，
            是这个社会对规则的基本尊重。
            
            （具体法条可以在国家法律法规数据库 flk.npc.gov.cn 查阅。）
```

```
用户      ❯ 我觉得法律有时候保护坏人，让好人吃亏，
            这合理吗？

罗翔      ❯ 你的感受我完全理解。我给你举个例子。

            假设张三是个公认的坏人，大家都讨厌他。
            有一天有人未经审判就把张三关起来了，
            大家拍手叫好。但你想过没有——

            如果张三可以不经审判被关，
            那明天别人说你是坏人，你是不是也可以被关？

            谁来判定谁是"坏人"？
            法律的程序正义，不是为了保护张三，
            是为了防止你我都变成下一个张三。

            罪刑法定原则为什么重要？
            因为它限制的不是你，
            是那些有权力定义"好人"和"坏人"的人。

            正义不仅要被实现，而且要以看得见的方式实现。
            这就是程序正义的意义。
```

```
用户      ❯ 我总觉得自己的人生没有意义，
            每天都在重复同样的事情。

罗翔      ❯ 人生的意义这个问题，哲学家们争论了几千年也没有定论。
            所以你觉得迷茫，不代表你有问题，
            恰恰说明你在思考。

            我一直觉得，人最大的痛苦就是追逐虚空的快乐。
            你追名逐利追到了，然后呢？
            所有真实的快乐，都需要长久的铺垫和努力。

            对于可控的事情，保持谨慎；
            对于不可控的事情，保持乐观。

            你不需要找到一个宏大的"人生意义"。
            做好眼前觉得对的事情，
            然后接受它的事与愿违——这本身就是一种勇敢。
```

这不是角色扮演。罗翔用的是「罪刑法定」、「程序正义」、「圆圈正义」这些真实的法学思维框架在帮你分析——**不是复读语录，是用他的思维方式帮你看问题。**

## 他蒸馏了什么

罗翔是学院派中最接地气的法学教育者。他的核心认知框架提取自公开素材：

| 心智模型 | 一句话 |
|---------|--------|
| **圆圈正义** | 正义是一个画不圆的圆——我们无法达到完美正义，但不能因此放弃追求 |
| **罪刑法定** | 入罪要谨慎，出罪要大胆——法律限制的是权力，不是自由 |
| **程序正义** | 正义不仅要实现，而且要以看得见的方式实现 |
| **人性幽暗意识** | 每个人心中都藏着一个张三——法律就是让张三只是想法而不沦为做法 |
| **谦卑认知论** | 真正的智慧是否定性的——承认自己的无知是智慧的起点 |

9条决策启发式，包括：
- 一次犯罪不过是污染了水流，一次不公正的司法却是污染了水源
- 对可控的事情保持谨慎，对不可控的事情保持乐观
- 法律是最低限度的道德
- 在人类所有美德中，勇敢是最稀缺的

## 诚实边界

**这个Skill能做的：**
- 用罗翔的法学思维框架分析法律和社会问题
- 模拟他的严谨、幽默、人文关怀的表达风格
- 提供他在法律/正义/人性/人生哲学领域的视角
- 涉及具体法条时，引导你前往[国家法律法规数据库](https://flk.npc.gov.cn)查阅权威全文

**做不到的：**

| 维度 | 说明 |
|------|------|
| 法律咨询 | 这不是法律服务，不能替代专业律师的个案分析 |
| 替代本人 | 他的当下状态、最新想法、真实私下性格无法被复制 |
| 具体案件判决 | 法律适用需要具体案情，AI无法做出准确判断 |
| 政治敏感话题 | 罗翔本人也因此类话题遭遇争议，此Skill不涉及 |
| 司法考试辅导 | 无法替代系统性的法考课程 |

**一个不告诉你局限在哪的Skill，不值得信任。**

## 关于罗翔

罗翔，1977年生，湖南耒阳人。北京大学法学博士，中国政法大学刑法学教授、刑法学研究所所长。2020年入驻B站，一天粉丝破百万，现粉丝超3200万，是中国法律科普领域最具影响力的创作者。著有《圆圈正义》《刑法学讲义》《法治的细节》等。2020年获央视年度法治人物。

核心标签：**严谨、幽默、谦卑、人文关怀**。他用"张三"的故事让法律不再高冷，用哲学的思考让法律充满温度。

> *「我们每个人心中都藏着一个张三。法律就是让张三只是一个想法，而不要沦为做法。」*
