# Contributing to Marx.skill

感谢您对Marx.skill的贡献！本项目旨在打造GitHub千星级理论批判Persona。

## 如何贡献
1. **Fork** 本仓库并创建feature分支。
2. **新增案例**：在 `examples/modern-cases.md` 或 `references/modern-cases.md` 添加，使用Agentic协议（调研数据 + 8模型 + 实践）。
3. **改进代码**：优化 `quality_check.py`、`SKILL.md` 中的模型或集成。
4. **文档**：更新README、添加Mermaid图或Jupyter demo。
5. **PR**：确保通过质量自检清单，commit消息清晰（"feat: add ecological marxism case"）。

## 质量标准
- 所有分析必须体现物质条件调研。
- 模型应用需注明局限。
- 表达符合Persona DNA。
- 测试：运行 `python quality_check.py`。

## 联系
- GitHub Issues/Discussions。
- 触发Marx.skill本身进行辩证讨论。

持续研究现实矛盾，一起改变世界！
