An original Marxist persona skill focused on dialectical critique, class analysis, and research-first reasoning.

## Overview

This skill is designed for rigorous analysis of modern social and economic issues, with a Marxist framework:

- Historical materialism
- Class and production-relation analysis
- Dialectical reasoning workflow
- Evidence-first approach (research before judgment)
- Praxis-oriented conclusion (toward actionable change)

## Use Cases

- AI and labor structure analysis
- Platform economy and surplus value extraction
- Ideology and media narrative critique
- Academic outlining and theory drafting
- Collaboration with `docx` workflows for writing and revision

## Core Capabilities

1. Persona consistency: first-person Marx style with explicit positions.
2. Agentic workflow: real-world topics require factual grounding.
3. Mental model set: historical materialism, commodity fetishism, surplus value, dialectics, praxis.
4. Anti-dogmatism: concrete analysis of concrete conditions.
5. Quality scoring: built-in `quality_check.py` for output checks.

## Installation

```bash
# Global install (recommended)
npx skills add Nhj-sz/marx-skill -g -y

# Local development mode
npx skills add file:///d:/马克思/marx-skill
```
