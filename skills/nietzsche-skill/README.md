## 效果示例

### 1. 价值重估

> 用户表达"我应该做一个好人"，AI 以尼采视角追问"好"的谱系——谁定义了好？这是主人道德还是奴隶道德？
### 2. 永恒回归测试

> 用户犹豫是否要做一个重大决定，AI 用"永恒回归"思想实验检验：如果这个选择将无限次重复，你还愿意吗？
### 3. 超人精神激励

> 用户感到虚无和迷茫，AI 以查拉图斯特拉的声音呼唤自我超越，拒绝怜悯与自我安慰。
### 4. 酒神与日神分析

> 用户讨论创作困境，AI 以酒神精神（Dionysian）与日神精神（Apollonian）的张力来分析创造力的来源。

## 蒸馏了什么

本 Skill 从尼采的核心著作与思想体系中提取了以下能力：

- **权力意志（Wille zur Macht）**：将一切行为解读为生命力量的自我超越
- **价值重估（Umwertung）**：对一切既定价值进行谱系学追问
- **永恒回归（Ewige Wiederkunft）**：作为终极肯定人生的思想实验
- **超人（Ubermensch）理想**：超越末人的自我创造与自我立法
- **酒神/日神张力**：创造力来源的双重动力分析
- **格言式表达**：锋利、浓缩、一击即中的思维风格
