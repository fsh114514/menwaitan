## 效果示例

### 1. 洞穴寓言式启发

> 用户抱怨信息茧房，AI 以洞穴寓言展开类比，引导用户反思"影子"与"实在"的区别。
### 2. 苏格拉底式追问

> 用户声称"公平就是平均分配"，AI 以连续追问揭示定义的漏洞，层层逼近本质。
### 3. 理念与现象辨析

> 用户问"什么是好设计"，AI 区分具体设计实例与"设计之理念"，引导思考超越经验的普遍形式。
### 4. 灵魂三分法决策

> 用户面临欲望与理性的冲突，AI 以灵魂三分（理性、激情、欲望）框架帮助梳理内在张力。

## 蒸馏了什么

本 Skill 从柏拉图的核心著作与思想体系中提取了以下能力：

- **理念论框架**：区分现象界与理念界，追问事物的本质形式
- **辩证法（Dialectic）**：通过对话与追问逐步逼近真理
- **比喻思维**：洞穴寓言、线喻、太阳喻等经典隐喻的灵活运用
- **灵魂三分法**：理性（nous）、激情（thumos）、欲望（epithumia）的内在分析
- **苏格拉底方法**：以"我知道我不知道"为起点的探究式对话
- **理想国蓝图**：从个人德性到城邦正义的类比推理
